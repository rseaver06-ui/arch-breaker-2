# Arch Breaker 2

A brick breaker built for Omarchy. It uses your Omarchy theme (and follows it when you switch), the system font, and Omarchy-style menus, so it feels like part of the desktop. Fully offline. No accounts, no tracking.

## Install

Open a terminal in this folder and run:

```sh
sh packaging/install.sh
```

That puts the game in `~/.local/opt/arch-breaker-2`, adds an **Arch Breaker 2** entry to your app launcher (Super + Space, then type "arch"), and draws an icon in your current theme. It never asks for your password. If pygame is missing, it tells you the one `pacman` command to run.

To update: get the new version of this folder and run the same command again. Your save file is kept.

To remove:

```sh
sh ~/.local/opt/arch-breaker-2/uninstall.sh
```

Your save file (`~/.local/share/arch-breaker-2/save.json`) is never deleted.

You can also play without installing: `python3 -m arch_breaker2` from this folder.

## How to play

Keep the ball up, break the wall. Where the ball hits the paddle sets its angle: the edges send it out steep, the middle sends it straight. **Moving the paddle as you hit adds a little spin**, which is how you curve the ball into gaps. The ball speeds up a bit with every paddle hit and tops out per level, so long rallies get tense on their own.

Catch the falling letters:

| Letter | Power-up |
|---|---|
| **W** | Wide paddle, 12 seconds |
| **S** | Shield: saves one lost ball (the line under your paddle) |
| **M** | Multiball |
| **P** | Passthrough: one-hit bricks break without bouncing, 8 seconds |
| **L** | Slow ball, 8 seconds |

When one brick is left, a 20-second count starts. Hit it and the count restarts; let it run out and the brick crumbles for no points. From level 8 the wall creeps down every 12 paddle hits.

**Modes**

- **Daily**: the same levels for everyone today. Your best score for today is shown on the title screen.
- **Endless**: a random seed, as far as you can go. Top 5 scores are kept. The game-over screen shows the seed; R retries it.
- **Versus**: see below.

## Controls

| | Keyboard |
|---|---|
| Move | Left / Right, or A / D |
| Launch | Space (also W or Up) |
| Pause | Esc or P |
| Fullscreen | F11 |
| Restart this seed | R (while paused or on game over) |
| Effects volume | `[` and `]` |
| Music volume | `-` and `=` |
| Mute | M |

## Versus (two players on one keyboard, or you against the CPU)

One shared wall. Each player has their own half of the bottom and their own ball.

- **Any ball that falls through your side costs you 25 points.** It doesn't matter whose ball it was. The ball comes back on your paddle a second later. There are no lives and nobody is knocked out.
- The ball's color shows who gets the points for the bricks it breaks: whoever touched it last. Catch the other player's ball and it's yours.
- The match ends when the wall is clear. Highest score wins.

Send your ball toward the other side and they have to deal with it. Catch theirs and you steal the scoring. That's the whole game.

| | P1 (left) | P2 (right) |
|---|---|---|
| Move | A / D | Left / Right |
| Launch | W | Up |

Against the CPU, pick Easy, Normal or Hard with Left/Right on the Versus screen.

## Settings

From the title screen or the pause menu: music track (or Random, or Off), effects volume, music volume, screen shake, brick shards.

## Theme

Colors come from `~/.local/state/omarchy/current/theme/colors.toml` (older installs: `~/.config/omarchy/current/theme/colors.toml`), read-only, checked twice a second. Switch themes and the game recolors mid-rally. All 22 stock themes are checked, light ones included. If the file is missing, a built-in palette is used.

## For the curious

`arch_breaker2/sim/` holds the rules and never touches graphics or input. `io/` turns a keyboard or a CPU player into the same small input record. `render/` only draws. Tests: `python3 -m pytest -q` (or `PYTHONPATH=. uvx pytest -q`). One test runs two full matches from the same seed and inputs and checks they stay identical, which is what online play will depend on. The design document is `docs/design.md`.
